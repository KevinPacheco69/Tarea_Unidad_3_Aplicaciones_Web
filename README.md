# FitMarket – Aplicación Web

Proyecto académico desarrollado para la asignatura **Aplicaciones Web – Unidad 3**, de la Universidad Politécnica Salesiana.

FitMarket es una aplicación web de equipamiento deportivo desarrollada con Vue 3, Node.js, Express y MySQL.

## Funcionalidades

- Catálogo de productos deportivos.
- Filtros por categorías.
- Formulario de contacto.
- Diseño adaptable a dispositivos móviles.
- Instalación como aplicación PWA.
- Acceso limitado al catálogo sin conexión.

## Tecnologías

- Vue 3 y Vite.
- JavaScript, HTML5 y CSS3.
- Node.js y Express.
- MySQL.
- Git y GitHub.

## Ejecución del proyecto

**1. Base de datos**

Iniciar MySQL desde XAMPP y configurar la base de datos `taskmanager_db` con las tablas necesarias.

**2. Backend**

Desde la carpeta `TaskManagerAPI`:

```bash
npm install
npm start
```

**3. Frontend**

Desde la carpeta `FitMarket/fitmarket-vue`:

```bash
npm install
npm run dev
```

Abrir en el navegador la dirección proporcionada por Vite, normalmente `http://localhost:5173`.
